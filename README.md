# Iconos alternativos Espakodi

18 iconos de los países hispanohablantes en PNG: 711 × 683 px, fondo transparente.

- `index.html` — galería con descarga individual
- `iconos/` — los 18 PNG
- `iconos-ek-hispano.zip` — los mismos, en un zip

Colombia y Ecuador comparten diseño, igual que El Salvador, Honduras y Nicaragua:
sus banderas solo cambian en el escudo o las estrellas, que aquí no están.
